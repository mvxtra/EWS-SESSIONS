# EWS SESSIONS — Android

Это первый тестовый Android-клиент EWS SESSIONS.

Он открывает текущий клуб `https://ews-sessions.onrender.com/` внутри полноэкранного Android WebView.

## Сборка

1. Открой папку `android` в Android Studio.
2. Дождись Gradle Sync.
3. Подключи Android-телефон с USB debugging или запусти эмулятор.
4. Нажми Run.

Следующим этапом можно добавить отдельные сенсорные WASD/поворот камеры и мобильную кнопку прыжка/сидения, чтобы клубом было удобно управлять пальцами.
